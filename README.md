# Ola Bike Ride Request Forecast

## Project Overview
This project is based on predicting the number of Ola bike ride requests using different features from the dataset. The model analyzes various environmental and seasonal conditions to forecast ride demand.

## Features Used
The dataset contains 12 features including:
- Datetime
- Season
- Weather
- Temperature
- Humidity
- Windspeed
- Holiday
- Working Day
- And other related features

## Technologies & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Models Used
- Linear Regression
- Random Forest Regressor
- Support Vector Machine (SVM)

## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Selection
5. Model Training
6. Prediction & Evaluation

## Objective
The main objective of this project is to predict the bike ride request count based on different weather and seasonal conditions.
